# Earn Karo 2.0 — Frontend Demo

## Run locally
1. Extract `earn-karo-2.0.zip`.
2. Open the `earn-karo-2.0` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. If using terminal and Python is installed, run from this folder:
   `python -m http.server 8000`
   Then open `http://localhost:8000`.

## Demo login
- Admin: `admin@earnkaro.demo` / `admin123`
- User: `user@earnkaro.demo` / `user123`

## Included
- Responsive dark-blue/neon UI
- Login and registration demo
- Separate user and admin navigation
- App listings, search and category filter
- Admin can add, edit and delete app listings
- Referral click log and demo commission ledger
- Local browser storage (localStorage)

## Important limitations
This is a working **frontend demo**, not a production earning/affiliate platform.
- Passwords and roles are stored in browser localStorage and are NOT secure.
- Anyone can choose the admin role while registering; admin access is not secure.
- Demo referral clicks do not prove sign-ups or generate real partner commissions.
- `example.com` links are placeholders. Replace each with your real approved referral URL.
- Real authentication, role permissions, multi-user data, verified partner conversions, secure admin controls and payout data require a backend, database, server-side sessions and partner APIs/postbacks.
- The commission numbers shown are illustrative only. Withdraw only through the official partner platform.
